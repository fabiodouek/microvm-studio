GitHub

A workspace reaches GitHub in one of two ways, chosen under Access in its GitHub section.

GitHub sign-in

In Settings → GitHub, choose Sign In to GitHub…. MicroVM Studio shows a code: Copy Code and Open GitHub, then approve it in your browser. Then choose Choose Repos… to install the GitHub App on the repos your MicroVMs may reach: a sign-in only reaches repos the app is installed on.

Once an account is signed in, the button reads Add Another GitHub Account…. It signs in another account too, such as a work one, and keeps the ones you have. GitHub approves the code for the account your browser is using, so switch to the other account on github.com before you enter the code. Each workspace chooses its account under Access, whose menu can sign in or add an account too.

MicroVM Studio has no server. Your sign-in stays on this Mac and goes only to your MicroVMs: the app's author never sees your code, your repos or your token.

MicroVMs get a short-lived token, at most 8 hours, never your sign-in. MicroVM Studio renews it when needed and sends the new one to the account's running MicroVMs. A sign-in reaches every repo you installed the app on, and can't be read-only: for that, use a token.

Sign Out… makes this Mac forget the sign-in. MicroVMs keep their current token until it expires; to revoke it at once, use GitHub → Settings → Applications.

A token

Choose Token, then Paste a Token…, or Import from gh… to copy the GitHub CLI's login. The token is saved in this Mac's Keychain. A fine-grained token limited to the repos the workspace needs is safest; a gh login is broad and doesn't expire.

Repos

Add Repo takes owner/name and an optional branch; Browse Repos… lists the repos your access reaches, to tick. Each repo is cloned when a MicroVM connects, if it isn't there yet: into your home folder, or into /workspace with persistent storage.

Inside the MicroVM, git gets the token through a credential helper and gh through GH_TOKEN. Both are refreshed each time a terminal connects.

Check Connection

Check Connection checks the access and each repo from this Mac, without touching any MicroVM. It shows who you're connected as, and for each repo Can push, Read-only, Public or Not found.
