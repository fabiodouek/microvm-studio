MicroVM Studio user guide

MicroVM Studio starts AWS Lambda MicroVMs from workspaces you set up, and gives each one a terminal on your Mac.

This is guide v0, for MicroVM Studio 0.x. The guide is versioned with the app's major version; older versions stay at their own address when a new one is published. The same pages are in the app, without the pictures, under Help → MicroVM Studio Help.

Start here

  • Quick start: from a new install to a running MicroVM, with GitHub and Claude Code. Needs no VPC.
  • A workspace that keeps its files: a network connector, an EFS file system, and a /workspace that outlives its MicroVMs.

Words used here

  • MicroVM: a small virtual machine run by AWS Lambda, in your account. It bills while it runs, can be suspended, and stops for good after at most 8 hours.
  • Workspace: what a MicroVM starts with: its image, repos, sign-ins, secrets, setup and limits. Saved on your Mac; you launch MicroVMs from it.
  • Image: what a MicroVM boots from, built in your account. It also sets the MicroVM's memory and CPU.
  • Network connector: how a MicroVM reaches the network: AWS's own internet egress, or one in your VPC.
