Codex

The starter image has Codex installed. Choose how it signs in under Sign-in in the workspace's Codex section, after Claude Code's. New workspaces start with None, unless Settings → General → New workspaces chooses a Codex sign-in for them. Set the start command to codex to open it when the session starts.

An OpenAI API key

Choose OpenAI API key, and pick the secret that holds your key, or New Secret… to add one. The key stays in this Mac's Keychain and goes only to your MicroVMs. Codex in the MicroVM gets it as OPENAI_API_KEY. A project key you can revoke is safest.

Sign in with ChatGPT

Choose Sign in with ChatGPT in the MicroVM. When you connect and Codex isn't signed in yet, the terminal runs codex login --device-auth, which shows a link and a code: open the link on any device, sign in, and enter the code. It all happens in the MicroVM, so no secret from this Mac goes into it. Press Control-C to skip it for now.

With a persistent /workspace, Codex keeps its sign-in in /workspace/.codex, so new MicroVMs from the workspace stay signed in, and no other workspace can reach it. Without one, each new MicroVM asks you to sign in again.

The image needs Codex

The starter image has it. One built before it did says A newer recipe is available. in Settings → Images: update it there. For an image of your own, tick Codex under Packages in Settings → Images. When the chosen image was built by MicroVM Studio without Codex, the Codex section says so. An image built elsewhere can't be checked: if Codex is missing when you connect, the terminal says Codex isn't installed in this image, so it can't sign in.
