Claude Code

The starter image has Claude Code installed. Choose how it signs in under Sign-in in the workspace's Claude Code section. Set the start command to claude to open it when the session starts.

Sign In with Claude

Choose Token from claude setup-token, then Sign In with Claude…. It runs claude setup-token on this Mac, so Claude Code must be installed here too. Finish signing in in your browser, and the token is saved in this Mac's Keychain without being shown. Or save a token you made elsewhere as a secret. The MicroVM gets it as CLAUDE_CODE_OAUTH_TOKEN.

An Anthropic API key

Choose Anthropic API key, and pick the secret that holds your Anthropic API key. The MicroVM gets it as ANTHROPIC_API_KEY.

Claude tokens and API keys can't be limited or made short-lived.

Amazon Bedrock

Choose Amazon Bedrock and no Anthropic secret goes into the MicroVM. Claude Code uses Bedrock in the workspace's region through the workspace's AWS role, which needs permission to call Bedrock. With no role chosen, Create a Role for Bedrock… makes one. If Claude Code says a model isn't available, check model access in the Bedrock console for that region.

Settings → General → New workspaces chooses between a token and Bedrock for new workspaces. For Codex, see Codex.
