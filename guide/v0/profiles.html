Profiles and Regions

MicroVM Studio works with any number of AWS profiles, and keeps separate settings for each. There's no default profile: Settings shows one profile at a time, and the profile it shows is the one new workspaces start on.

The profile switcher

The top of Settings → General, Network, Images and Storage says AWS profile:, with the profile's name and badge in its own colour. Open it to choose another profile, or Add a Profile… to sign in with IAM Identity Center. The menu ticks the profile shown. Reload Profiles reads ~/.aws again, after aws configure or an edit of your own. Beside the menu, the profile says Signed in or Sign-in needed, with Sign In… for an IAM Identity Center profile; in the menu, the other profiles say what the last listing found. Every one of those tabs follows the switcher, so you always know whose settings you are changing. In General, the sections under All profiles (New workspaces, Notifications and Updates) don't follow it: they apply to every profile.

These belong to one profile: its regions to list, its default region, its network connectors, its images and its file systems. GitHub, Secrets and Terminal are the same for every profile.

The main window's sidebar groups workspaces under their profile's badge, and nothing is hidden when you change the profile in Settings. A workspace has its own profile, which the workspace editor can change: its Region menu then offers the regions listed for that profile, whichever profile Settings shows.

Regions to list

Settings → General → Regions to list shows the regions you added, each with Remove, and one pop-up with Add for another region. A profile lists only its default region until you add more. Choose the Default region from the listed ones: it is always listed, so it can't be removed.

  • The pop-up offers every AWS region. The ones MicroVMs are known to run in say MicroVMs available and are added at once.
  • Any other region is checked when you press Add, with one harmless call to Lambda MicroVMs there. If that works, the region is added.
  • If MicroVMs aren't there, the message says Lambda MicroVMs aren't available in the region, and nothing is added.
  • If the check couldn't be made, such as when the sign-in has expired or a permission is missing, the message says so, and Add Anyway adds the region regardless.

Regions listed here are the ones the main window and the menu bar list, and the ones the other tabs offer. See Troubleshooting for what to do when a region won't add.

Settings from older versions

The profile that was the default opens first in Settings, with the regions to list and the default region it had. Every other profile starts with its own default region listed, and nothing else.
