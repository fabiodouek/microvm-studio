Keyboard Shortcuts

Terminals

  • ⌘D: Split Right
  • ⇧⌘D: Split Down
  • ⇧⌘W: Close Pane
  • ⌘] and ⌘[: Next Pane and Previous Pane
  • ⌘W: Disconnect, or close the window when no terminal is shown
  • ⌘K: Clear
  • ⌘F, ⌘G, ⇧⌘G and ⌘E: Find…, Find Next, Find Previous and Use Selection for Find
  • ⌘+, ⌘− and ⌘0: Bigger, Smaller and Actual Size text
  • Return, over a pane's message: its main button, such as Reconnect, Try Again or Resume and Reconnect. Setup's Cancel has no shortcut, so Escape never stops setup.

The main window

  • ⌘N: New Workspace…
  • ⌘R: Refresh the list of MicroVMs
  • Return on a connected MicroVM in the sidebar: move the keyboard into its terminal
  • ⌥⌘S: Focus Sidebar, to move the keyboard back from a terminal to the list
  • Escape, with the keyboard in the list: select nothing
  • Tab moves between controls, as in any window

The app

  • ⌘?: MicroVM Studio Help
  • ⌘,: Settings
  • ⌘Q: Quit
