Install

MicroVM Studio is a Mac app. It's free, and one download runs on every supported Mac.

What you need

  • A Mac with macOS 15 (Sequoia) or later. The same download runs on Apple silicon and on Intel Macs.
  • An AWS account in a region with Lambda MicroVMs. AWS lists them on the Lambda MicroVMs page.
  • An AWS profile on your Mac, in ~/.aws/config or ~/.aws/credentials. The AWS CLI isn't needed.

Install

  1. Download

    Download MicroVM Studio

    The file is MicroVMStudio.dmg, about 40 MB. Its checksum is on the release page.

  2. Copy it to Applications

    Open the disk image and drag MicroVM Studio onto the Applications folder. Then eject the disk image.

  3. Open it

    Open MicroVM Studio from Applications. The first time, macOS asks whether to open an app downloaded from the internet: choose Open. The app is signed with a Developer ID and notarized by Apple, so no security setting has to change.

  4. Start

    The main window opens on Get started. Carry on with the Quick start.

What macOS asks for

  • Keychain: the app keeps your GitHub sign-in and other secrets in your Mac's Keychain. macOS may ask before the app reads one back.
  • Files: the app reads your AWS profiles in ~/.aws, and the files you choose to upload.

Updates

The app checks for updates by itself and tells you when there's one. MicroVM Studio → Check for Updates… checks now. Settings → General has the switches for automatic checks and automatic installs.

Remove it

First terminate your MicroVMs and delete what the app made in AWS, in Settings: images, file systems and network connectors stay in your account otherwise. Then drag the app from Applications to the Trash. Its settings and workspaces are in ~/Library/Application Support/MicroVMStudio.
